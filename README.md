# 노후 자금 고갈 시뮬레이터 (똑재TV)

국민연금·퇴직금·연금저축·IRP·ISA·예금을 넣으면 은퇴 후 해마다 생활비를 어디서 꺼내고
세금과 건강보험료(건보료)를 얼마나 내는지 계산해 **자금이 바닥나는 나이**를 보여 주는 단독 HTML 시뮬레이터입니다.

- 사이트: https://ttokjaetv.github.io/retire-drawdown/
- 기준: 2026년 10월 현행 소득세법 · 2026년 건강보험료 (단순화 계산 · 세무·투자 자문 아님)
- 최초 제작: 2026-10-13

## 파일 구조

```
index.html          ← 배포 완성본 (직접 고치지 말고 src를 고친 뒤 빌드)
src/engine.js       ← 계산 엔진 (화면과 무관한 순수 계산, node 겸용)
src/template.html   ← 화면. /*__ENGINE__*/ 자리에 엔진이 들어감
src/build.py        ← template + engine → index.html
src/test.js         ← 손계산 대조 테스트
```

```bash
cd src && node test.js        # ALL PASS 확인
cd .. && python src/build.py  # index.html 다시 만들기
```

## 계산 방식 요약

- 연금계좌 운용수익은 모두 ③, 손실은 ③ → ② → ① 순서로 차감(소득세법 시행령 제40조의3 ⑤, pension-tax-sim과 같음)
- 1년 단위. 은퇴 전: 남은 돈에 은퇴 전 수익률 → 연말에 그해 납입(연금저축·IRP 연 1,800만원 중 900만원까지 ③, 넘는 돈 ①, 소득 없는 배우자는 모두 ①; ISA 연 2,000만원)
- 은퇴하는 해: 퇴직금 일시금이면 퇴직소득세 뗀 돈을 예금·일반계좌로, IRP 연금이면 세전 금액을 ②로
- 은퇴 후 매년 초: 필요한 돈 = 생활비(물가 반영) + 건보료 + 공적연금 소득세 − 공적연금 → 세금까지 얹어 계좌에서 꺼냄 → 실제 세금으로 다시 맞춤
- 꺼내는 순서: 6가지 순서 × 국민연금 받기 전 ③ 상한 3가지(1,500·2,000·2,500만원) = 18가지를 모두 계산해, 바닥나는 해가 가장 늦고 같으면 다 찾았을 때 남는 돈이 가장 많은 조합 선택
- 연금계좌는 계좌를 나눠 둔 것으로 보고 ②·③ 수령한도를 따로 계산(③ 연차는 55세부터, ② 연차는 은퇴한 해부터)
- 건보료: 지역가입자 한 세대(공적연금 50% + 1인 1,000만원 넘는 이자·배당 + 재산 점수), 오늘 돈 가치로 계산 후 물가만큼 키움. 월 건강보험료(소득분·재산분 각각)와 장기요양보험료(버림한 건강보험료 기준)는 고지서처럼 10원 미만 버림(fin-income-tax와 같은 방식). 판정 기준 금액(1,000만·2,000만·5.4억/9억)은 법정 명목 금액이라 물가연동 안 함(명목 소득·재산과 비교). 피부양자 체크 시 요건(소득 부부 함께·재산 각자) 충족 해는 0원
- 예금·일반계좌: 세금은 수익 전체에 해마다 15.4%(국내상장 해외 ETF의 매도 시 세금을 미리 떼는 보수적 단순화). 건보료·금융소득종합과세 판정용 이자·배당은 종목 모드면 배당 + 그해 판 금액의 차익(원금 `Tb` 추적), 직접 입력이면 수익 전체
- 세법 기준금액: 기본은 현행 금액 고정. '세법 기준 물가연동'(`p.taxIndex`)을 켜면 연금소득공제·과표구간·인적공제·1,500만원·2,000만원을 물가만큼 키움(오늘 돈 가치로 세금 계산 후 물가 곱하기)
- '은퇴 후 세금 합계'에는 은퇴 전 적립 기간 일반계좌 세금(`sum.taxDivPre`)을 넣지 않음
- 최대 생활비: 계획 나이까지 버티는 월 생활비를 이분 탐색(오늘 돈 가치, 10만원 단위 내림 — 화면에도 표시)
